# 🎬 MovieXplore - Modern Movie Discovery App

MovieXplore කියන්නේ පරිශීලකයන්ට ඉතාමත් පහසුවෙන් සහ ආකර්ෂණීය අතුරුමුහුණතක් (UI) හරහා නවතම චිත්‍රපට ගවේෂණය කිරීමට සහ ඒවා සුරැකීමට (Save) හැකි වන සේ නිර්මාණය කළ වෙබ් යෙදුමකි. 

## ✨ විශේෂාංග (Features)

*   **Real-time Movie Search:** TMDB API එක භාවිතයෙන් ක්ෂණිකව ඕනෑම චිත්‍රපටයක් සෙවීමේ හැකියාව.
*   **Trending Movies:** දැනට ලොව පුරා ජනප්‍රියම චිත්‍රපට මුල් පිටුවෙන්ම දැකගත හැක.
*   **Modern Glassmorphism UI:** Tailwind CSS භාවිතයෙන් නිමවූ ඉතාමත් සුමට සහ නවීන පෙනුම.
*   **Watchlist/Save System:** ප්‍රියතම චිත්‍රපට Save කර තබා ගැනීමේ හැකියාව (Browser LocalStorage භාවිතා කර ඇත).
*   **Fully Responsive:** ජංගම දුරකථන සහ පරිගණක යන ඕනෑම උපකරණයකට ගැළපෙන සේ සකසා ඇත.

## 🛠️ භාවිතා කළ තාක්ෂණයන් (Technologies Used)

*   **Frontend:** HTML5, Tailwind CSS
*   **Scripting:** Vanilla JavaScript (ES6+)
*   **API:** [The Movie Database (TMDB)](https://www.themoviedb.org/documentation/api)
*   **Icons:** FontAwesome
